# chat-kit — общий набор для переписки

Одна основа переписки с клиентами для нескольких проектов: Атлас CRM, TishCRM (Dental AI CRM) и студия бота
(Muras AI Studio, проект aibots). Решение пользователя от 27.09.2026 — вариант Б «общий набор».

Что входит:
- **Окно переписки.** Список диалогов и «Ждут ответа». Лента как в WhatsApp с автором каждого сообщения: клиент, бот,
  менеджер, менеджер с телефона. Поле ввода с шаблонами и файлами. Голосовые, просмотр фото с лупой и поворотом, поиск
  внутри переписки, уведомления.
- **«Розетка» для каналов.** Приём сообщений без повторов и в правильном порядке, файлы, клиент по телефону, пауза бота,
  передача менеджеру. Подключения: Nextbot сейчас, шлюз WhatsApp из TishCRM, позже — своя студия. Смена подключения —
  настройка, а не переписывание.

Каждый проект хранит своих клиентов, сообщения и права сам. Набор получает от проекта только «переходник» к его базе.

План работ и решения — в артефакте «ИИ-продажник вместо Nextbot»
(https://claude.ai/artifact/9ceNCMMv2g9Lbj14oBX3Yc) и в этом репозитории, по мере работы.
