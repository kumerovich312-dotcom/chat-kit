# chat-kit — основа переписки с клиентами

Нейтральная основа переписки с клиентами для CRM на Next.js. Проект берёт её и докручивает под свою отрасль —
у клиники пациенты и запись на приём, у агентства кандидаты и вакансии, у магазина заказы, — не правя саму основу:
через «паспорт проекта» (слова, цвета, что включено), свои карточки в ленте и свои кнопки в поле ввода.

Что входит:
- **Окно переписки.** Список диалогов и «Ждут ответа», лента как в WhatsApp с автором каждого сообщения (клиент, бот,
  менеджер, менеджер с телефона), поле ввода с шаблонами и файлами, голосовые, просмотр фото с лупой и поворотом,
  поиск внутри переписки, уведомления, места для ИИ-бота (кнопки бота, «второй пилот», обучение, память).
- **«Розетка» для каналов.** Приём сообщений без повторов и в правильном порядке, файлы, клиент по телефону, пауза
  бота, передача менеджеру. Подключения: Telegram, WhatsApp, Instagram, почта, звонки, чат на сайте, Nextbot, ИИ-студия.
- **Ядро без базы.** Модель сообщения, правило «ждут ответа» (на TypeScript и подзапросом для Postgres), телефоны,
  файлы, разметка ответа бота под канал, время по поясу компании.

Каждый проект хранит своих клиентов, сообщения и права сам. Набор получает от проекта только «переходник» к его базе.

## Разработка набора

```bash
npm install
npm run demo        # демо-страница: http://127.0.0.1:30030
npm run check       # типы, тесты, сборка
npm run release     # новый выпуск на GitHub — только по «да» владельца
```

Пробный прогон выпуска, без метки и публикации: `npm run release -- --dry-run`.
