# Версии набора

Проект ставит нужную версию ссылкой (docs/CONNECT.md) и обновляется, когда сам решит — в своём чате, по своим проверкам.

## 0.1.0 — 27.09.2026

Первая версия.

- **Ядро.** Сообщение с автором (клиент, бот, менеджер из CRM, менеджер с телефона, администратор, система); порядок
  и повторы; правило «ждут ответа» на TypeScript и подзапросом для Postgres (совпадение проверено на 300 случайных
  диалогах); телефоны с кодом страны (+7 сравнивается целиком); файлы; разметка ответа бота под канал (WhatsApp,
  Telegram, текст); время по поясу компании до секунды; ссылки wa.me / t.me и приветствие.
- **«Розетка» каналов и «переходник» к базе проекта.** Приём уведомлений без повторов, файлы после ответа каналу,
  скачивание с проверками, тип файла по содержимому, подписанные ссылки на файлы (совместимы с Атласом и TishCRM).
- **Подключения.** Nextbot — перенесён из Атласа и отделён от его базы (прежние ключи повтора сохранены); шлюз WhatsApp
  TishCRM — очередь исходящих через проект и управление по HTTP; студия — заготовка по разделу 10.8 её плана.
- **Окно переписки** (React 19, свои стили на переменных `--ck-*`, без Tailwind). Список и «Ждут ответа», лента как
  в WhatsApp, поле ввода с вкладками «Клиенту / В историю / Заметка / Письмо», шаблоны и файлы, сообщение сразу с
  часиками, голосовые с волной и перемоткой, просмотр фото с лупой и поворотом, PDF / Word / Excel, поиск в переписке,
  уведомления — один звонок на одно ожидание.
- **Места для студии** (решения пользователя 27.09.2026): кнопки бота в шапке, «второй пилот», оценка ответов бота
  и «как надо было», «Сделать примером для бота», «Что бот знает о клиенте».
