# Версии набора

Проект ставит нужную версию ссылкой (docs/CONNECT.md) и обновляется, когда сам решит — в своём чате, по своим проверкам.

## 0.1.0 — готовится

Первая версия (ещё не выпущена).

- **Ядро.** Сообщение с автором (клиент, бот, менеджер из CRM, менеджер с телефона, администратор, система); порядок
  и повторы; правило «ждут ответа» на TypeScript и подзапросом для Postgres (совпадение проверено на 300 случайных
  диалогах), звонки в нём учитываются; телефоны с кодом страны (+7 сравнивается целиком); файлы; разметка ответа бота
  под канал (WhatsApp, Telegram, текст); время по поясу компании до секунды; ссылки wa.me / t.me и приветствие; цитаты,
  карточки проекта, расшифровка голосовых, статусы, метки, ответственный, оценка ИИ, присутствие коллеги.
- **«Розетка» каналов и «переходник» к базе проекта.** Приём уведомлений без повторов, файлы после ответа каналу,
  скачивание с проверками, тип файла по содержимому, подписанные ссылки на файлы, звонки как событие канала.
- **Подключения.** Nextbot (прежние ключи повтора сохранены, функции бота — любые), заготовка ИИ-студии.
- **Окно переписки** (React 19, свои стили на переменных `--ck-*`, без Tailwind). Список и «Ждут ответа», лента как
  в WhatsApp, поле ввода с вкладками «Клиенту / В историю / Заметка / Письмо», шаблоны и файлы, сообщение сразу с
  часиками, голосовые с волной и перемоткой, просмотр фото с лупой и поворотом, PDF / Word / Excel, поиск в переписке,
  уведомления — один звонок на одно ожидание.
- **Места для ИИ-бота**: кнопки бота в шапке, «второй пилот», оценка ответов бота и «как надо было», «Сделать примером
  для бота», «Что бот знает о клиенте».
- **Паспорт проекта**: слова отрасли в нужных падежах (клиент, пациент, кандидат…), что включено, метки, свои карточки
  в ленте, свои кнопки в меню «+», цвета.
- **Окно** (выбор пользователя 27.09.2026): фильтр сообщений, все файлы клиента, полоса статуса, меток и ответственного,
  «срочно» / «недоволен» в списке, «Кратко», ответ с цитатой, запись голосового, «Расшифровать», «Улучшить текст»,
  старые сообщения при прокрутке вверх, тёмная тема, «коллега уже отвечает».
- **Каналы**: Telegram-бот, WhatsApp через GREEN-API, Instagram Direct, почта (Postmark или любой мост JSON), звонки
  (общий вебхук любой АТС и Zadarma), чат на сайте с виджетом.
- **«Розетка ИИ»**: Claude, сервис расшифровки с API как у OpenAI, поддельный ИИ для демо.
- **Команда и статистика**: статусы и «отложить до», раздача новых диалогов, метки, присутствие коллег, скорость
  ответов (TypeScript и подзапрос для Postgres).
- **Инструкция для ИИ проекта** (docs/FOR-AI.md); описания входят в выпуск.
