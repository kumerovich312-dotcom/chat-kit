# Помощник ИИ в переписке («розетка ИИ»)

Часть набора `@muras/chat-kit/ai`: четыре помощника для сотрудников в окне переписки. Код — `src/ai`, проверки —
`tests/ai`. Ключи поставщиков хранит проект в своём окружении; набор ключей не хранит и сам никуда не ходит.

## Что видит сотрудник

| Кнопка или пометка | Что делает | Кто делает |
|---|---|---|
| «Расшифровать» у голосового и записи звонка | превращает речь в текст; текст остаётся под файлом | сервис расшифровки (OpenAI или похожий) |
| «Кратко» в шапке диалога | 1–3 предложения: кто обратился и чего хочет, что сделано, на чём остановились; и до 5 пунктов | Claude |
| «Улучшить» у поля ввода | правит черновик менеджера: «Улучшить» (грамотно и вежливо), «Короче», «Теплее», «Исправить ошибки» | Claude |
| Настроение и срочность в списке диалогов | «недоволен», «срочно» и одна фраза почему: «третий раз спрашивает, где заказ» | Claude, дешёвая модель, само после сообщения клиента |

Улучшенный текст возвращается в поле ввода — отправляет его менеджер сам, после проверки. Клиенту ИИ ничего не пишет.

## Как устроено

«Розетка ИИ» (`ChatAi`) — четыре дела: `transcribe`, `summarize`, `improve`, `assess`. У каждого ответ одного вида:
`{ ok: true, value }` или `{ ok: false, error, retryable }`. `error` — готовая фраза по-русски для сотрудника,
`retryable: true` — стоит показать «Повторить» (сбой связи, ИИ перегружен). Исключений окно не получает никогда.

Поставщики:
- `createClaudeAi` — Claude (Anthropic) для текста: «Кратко», «Улучшить», оценка;
- `createOpenAiCompatibleTranscriber` — расшифровка речи: OpenAI, Groq или свой сервер с тем же API;
- `fakeAi` — поддельный ИИ без сети и ключей: для демо-страницы и проверок.

`combineAi(...)` собирает из них один помощник: каждое дело берёт первый поставщик, который его умеет. Чего нет —
того метода нет, и окно не показывает кнопку: `aiCaps(ai)` даёт простые «да/нет» для страницы.

## 1. Кабинеты поставщиков

**Claude** — console.anthropic.com:
1. Создать ключ API (раздел API Keys).
2. Пополнить баланс (Billing) — без денег на счёте ИИ отвечает «Закончились деньги на счёте ИИ».
3. По желанию — предел расходов в месяц, чтобы случайная ошибка в проекте не потратила много.

**Расшифровка** — одно из двух:
- OpenAI — platform.openai.com: ключ API (API keys), пополнить баланс (Billing), предел расходов (Limits);
- Groq — console.groq.com: ключ API (API Keys). Дешевле, модели Whisper; у бесплатного тарифа — ограничения по числу
  запросов в минуту.

## 2. Что проект хранит в окружении

Ключ Claude и ключ сервиса расшифровки — только в окружении проекта (переменные окружения на сервере, секреты
хостинга). Не в коде, не в базе, не в браузере: ключ позволяет тратить деньги компании. Имена переменных — на выбор
проекта. Весь код ниже работает только на сервере; файл с ключами не подключать в клиентские компоненты.

## 3. Один файл помощника

```ts
// src/lib/ai.ts — только сервер
import { combineAi, createClaudeAi, createOpenAiCompatibleTranscriber } from "@muras/chat-kit/ai";

const claudeKey = process.env.AI_CLAUDE_KEY; // имена переменных — свои
const voiceKey = process.env.AI_VOICE_KEY;

export const ai = combineAi(
  claudeKey ? createClaudeAi({
    apiKey: claudeKey,
    timeZone: "Asia/Bishkek",                          // пояс компании — время сообщений как у сотрудников
    words: { client: "клиент", company: "магазин" },   // слова проекта: «пациент» и «клиника», «кандидат» и «агентство»
  }) : null,
  voiceKey ? createOpenAiCompatibleTranscriber({ apiKey: voiceKey }) : null,
);
```

Нет ключа — нет и кнопок: `combineAi` пропускает пустые места.

Расшифровка через Groq — адрес и модель:

```ts
createOpenAiCompatibleTranscriber({
  apiKey: voiceKey,
  baseUrl: "https://api.groq.com/openai/v1",
  model: "whisper-large-v3-turbo", // или whisper-large-v3 — точнее и дороже
});
```

Другие настройки Claude (все необязательные):
- `models: { summarize, improve, assess }` — свои модели (ниже — какие);
- `effort` — сколько модели думать перед ответом: по умолчанию `"low"` (быстро и дёшево, пересказу и правке хватает),
  `"medium"` — вдумчивее, `null` — как решит модель;
- `maxInputChars` — не больше стольких знаков переписки или черновика в одном запросе (по умолчанию 24 000);
- `maskPersonalData: false` — отправлять телефоны и почту как есть (не советуем, см. «Что уходит поставщику»);
- `onUsage` — расход каждого запроса для своего журнала затрат: `{ task, model, inputTokens, outputTokens }`;
- `baseUrl` — свой шлюз к Claude, если компания ходит к нему через посредника.

## 4. Модели и сколько стоит

Токен — кусочек слова; по токенам поставщики считают цену. Цены — ориентир на 2026 год: проверьте на сайте поставщика.

| Дело | Модель по умолчанию | Почему | Цена модели (за 1 млн токенов: запрос / ответ) |
|---|---|---|---|
| «Кратко», «Улучшить» | `claude-sonnet-5` | нажимают руками, важно качество | $2 / $10 |
| Оценка | `claude-haiku-4-5-20251001` | идёт на каждое сообщение клиента — нужно дёшево и быстро | $1 / $5 |
| Сильнее и дороже (по желанию) | `claude-opus-5-5` | если пересказ или правка текста не устраивают | $4 / $20 |

Примерно на одно действие:
- **оценка** — около 0,2 цента: 1000 оценок в день — около 2 долларов в день;
- **«Кратко»** — 1–3 цента за длинную переписку (до 80 сообщений), меньше — за короткую;
- **«Улучшить»** — меньше цента;
- **расшифровка** минуты речи: OpenAI `gpt-4o-transcribe` — около 0,6 цента, `gpt-4o-mini-transcribe` — вдвое дешевле;
  Groq `whisper-large-v3-turbo` — меньше 0,1 цента.

Оценка — самая частая: она идёт сама после сообщений клиента. Её можно сделать реже (раздел 6) или выключить совсем:

```ts
const claude = claudeKey ? createClaudeAi({ apiKey: claudeKey }) : null;
export const ai = combineAi(
  // Без оценки: только «Кратко» и «Улучшить»
  claude && (process.env.AI_ASSESS === "off" ? { summarize: claude.summarize, improve: claude.improve } : claude),
  voiceKey ? createOpenAiCompatibleTranscriber({ apiKey: voiceKey }) : null,
);
```

## 5. Кнопки — действия на сервере

Действие-форма (server action) — функция на сервере, которую вызывает страница. Права проверяет проект, как для
просмотра переписки. `requireUser`, `loadFile`, `loadMessages`, `saveTranscript` — свои функции проекта; сообщения —
в виде `ChatMessage` набора, те же, что видит окно.

```ts
// src/app/inbox/ai-actions.ts
"use server";
import type { ImproveMode } from "@muras/chat-kit/ai";
import { ai } from "@/lib/ai";

/** «Расшифровать» у голосового или записи звонка */
export async function transcribeFile(fileId: string) {
  const me = await requireUser();
  const f = await loadFile(me.orgId, fileId);          // { data: Uint8Array, mime, name, transcript }
  if (!f) return { error: "Файл не найден" };
  if (f.transcript) return { text: f.transcript };     // уже расшифрован — второй раз не платим
  if (!ai.transcribe) return { error: "Расшифровка не подключена" };
  const r = await ai.transcribe({ data: f.data, mime: f.mime, name: f.name });
  if (!r.ok) return { error: r.error, retry: r.retryable === true };
  await saveTranscript(me.orgId, fileId, r.value.text); // окно покажет текст под файлом (Attachment.transcript)
  return { text: r.value.text };
}

/** «Кратко» в шапке диалога */
export async function summarizeDialog(clientId: string) {
  const me = await requireUser();
  if (!ai.summarize) return { error: "Краткое содержание не подключено" };
  const messages = await loadMessages(me.orgId, clientId, { last: 80 });
  const r = await ai.summarize(messages, { timeZone: me.timeZone });
  return r.ok ? r.value : { error: r.error, retry: r.retryable === true }; // { summary, points }
}

/** «Улучшить» у поля ввода: текст вернётся в поле, отправляет менеджер сам */
export async function improveDraft(text: string, mode: ImproveMode, channel: string) {
  await requireUser();
  if (!ai.improve) return { error: "«Улучшить» не подключено" };
  const r = await ai.improve(text, { mode, channel }); // mode: polish | shorter | friendlier | fix
  return r.ok ? { text: r.value.text } : { error: r.error, retry: r.retryable === true };
}
```

Подсказки:
- язык записи (`{ lang: "ru" }`) задавайте, только если он точно известен: клиент может говорить и по-кыргызски;
  без языка сервис определит его сам;
- `{ prompt: "Айгерим, рассрочка, самовывоз" }` — слова компании, которые сервис должен расслышать правильно;
- `{ focus: "запись и оплата" }` у «Кратко» — на что обратить особое внимание;
- подписи режимов для кнопок — `IMPROVE_LABEL`, какие кнопки показать — `aiCaps(ai)` (функции в клиентскую часть
  страницы передать нельзя, а «да/нет» — можно).

## 6. Настроение и срочность — после сообщения клиента

Оценку делает проект сам, когда пришло сообщение клиента: в маршруте приёма уведомлений канала, после ответа каналу
(`after` из `next/server`), чтобы канал не ждал ИИ.

```ts
// src/app/api/<канал>/route.ts — приём уведомлений канала
import { after } from "next/server";
import { ingest, jsonResponse, readWebhook } from "@muras/chat-kit/server";
import { assessDialog } from "@/lib/assess";

export async function POST(req: Request) {
  const input = await readWebhook(req);
  if (!input) return jsonResponse({ status: 413, body: { ok: false, error: "Слишком большой запрос" } });
  // adapter, store, orgId — как в маршруте канала (docs/CONNECT.md и описания каналов)
  const r = await ingest(adapter, store, input, { later: after });
  const clientId = r.summary.contactId;
  if (r.summary.status === "ok" && clientId) after(() => assessDialog(orgId, clientId));
  return jsonResponse(r);
}
```

```ts
// src/lib/assess.ts
import { fromClient } from "@muras/chat-kit";
import { ai } from "@/lib/ai";

export async function assessDialog(orgId: number, clientId: string) {
  if (!ai.assess) return;
  // Клиент часто пишет пачкой: не чаще раза в минуту на диалог. markAssessing — своя функция проекта: ставит отметку
  // времени у диалога и отвечает «нет», если с прошлой прошло меньше 60 секунд (отметку — до запроса к ИИ)
  if (!(await markAssessing(orgId, clientId, 60))) return;
  const messages = await loadMessages(orgId, clientId, { last: 20 });
  const last = messages.at(-1);
  if (!last || !fromClient(last)) return;            // последнее слово — за клиентом
  const r = await ai.assess(messages, { timeZone: "Asia/Bishkek" });
  if (r.ok) await saveAssessment(orgId, clientId, r.value); // { mood, urgency, reason, at }
  else console.warn("Оценка ИИ не удалась:", r.error);
}
```

Где хранить: у диалога (клиента) — одно поле JSON или четыре столбца (`mood`, `urgency`, `reason`, `at`). Список
диалогов отдаёт оценку в `DialogSummary.assessment` — окно покажет пометку. `mood`: `positive` / `neutral` /
`negative`; `urgency`: `low` / `normal` / `high`. Срочные можно поднимать выше в «Ждут ответа».

## Что уходит поставщику

- **Claude** получает текст последних сообщений (для «Кратко» — до 80, для оценки — 20) в таком виде:

  ```
  [12.10 14:03] Клиент: Здравствуйте, можно записаться на завтра? Мой номер {{PHONE_1}}
  [12.10 14:05] Менеджер Айгерим: Да, есть время в 15:00.
  [12.10 14:06] Менеджер Айгерим (заметка команды, клиент не видел): перезвонить после обеда
  [12.10 14:10] Клиент: (голосовое, расшифровка: «Хорошо, тогда в три»)
  ```

  Идут: время, кто написал (клиент — словом, сотрудник — по имени), текст, заметки команды (с пометкой), расшифровки
  голосовых и звонков, названия документов. Не идут: имя и карточка клиента из CRM, служебные строки, черновики бота,
  сами файлы. «Улучшить» отправляет только черновик.
- **Телефоны, почта и номера карт** в тексте заменяются метками `{{PHONE_1}}`, `{{EMAIL_1}}`, `{{CARD_1}}` до отправки;
  в ответе ИИ набор ставит их обратно — сотрудник видит настоящий номер, поставщик — нет. Номер карты в краткое
  содержание и в оценку не возвращается («номер карты»), в улучшенный черновик — возвращается.
- Маска узнаёт номера, записанные цифрами. **Не скрываются**: имена, адреса, номера документов с буквами, номера,
  написанные словами. Имена сотрудников идут как есть — если это нежелательно, передавайте сообщения без `author.name`.
- **Расшифровка** отправляет сам файл записи: в голосе номер не скрыть. Имя файла не отправляется (в нём бывает имя или
  номер клиента) — только «audio.ogg».
- Данные уходят на серверы поставщика за рубежом. Условия их хранения у поставщиков разные — проверьте их и упомяните
  поставщиков ИИ в политике обработки персональных данных компании как посредников.

## Ошибки

| Что случилось | Что видит сотрудник | «Повторить» |
|---|---|---|
| ключ неверный или отозван | «Ключ ИИ не подходит — проверьте настройки проекта» | нет |
| кончились деньги на счёте | «Закончились деньги на счёте ИИ — пополните баланс у поставщика» | нет |
| слишком много запросов | «ИИ перегружен запросами — повторите через минуту» | да |
| перегрузка или сбой у поставщика | «ИИ сейчас перегружен — повторите чуть позже», «Сбой на стороне ИИ (500) — …» | да |
| не ответил вовремя (текст — 30 с, расшифровка — 60 с) | «ИИ не ответил за 30 секунд — попробуйте ещё раз» | да |
| нет связи | «Нет связи с ИИ — попробуйте ещё раз» | да |
| модель не та | «ИИ: модель «…» не найдена — проверьте название модели и адрес в настройках проекта» | нет |
| запись больше 25 МБ | «Запись слишком большая для расшифровки: 31,2 МБ, можно до 25,0 МБ» | нет |
| формат записи не подошёл | «Сервис расшифровки не принял формат записи (amr) — подходят mp3, m4a, ogg, wav, webm» | нет |
| в записи тишина | «В записи не нашлось речи — расшифровывать нечего» | нет |
| ИИ ответил не по форме | «ИИ ответил не по форме — попробуйте ещё раз» | да |

У сервиса расшифровки те же фразы, но «сервис расшифровки» вместо «ИИ». Сам набор запрос не повторяет: решает
сотрудник кнопкой или проект (например, оценку можно повторить через минуту).

## Проверка без ключей

`fakeAi()` отвечает без сети и всегда одинаково: «(пример расшифровки) …», пересказ из последних сообщений клиента,
«Улучшить» — заглавная буква и точка, оценка — по словам «срочно», «жалоба», «спасибо». Для демо и проверок окна:

```ts
export const ai = process.env.AI_FAKE === "1" ? fakeAi({ delayMs: 600 }) : combineAi(/* … */);
```

## Ограничения

- Claude не расшифровывает речь — для голоса нужен отдельный сервис (раздел 1).
- Форматы записи: mp3, mp4, m4a, ogg (голосовые WhatsApp и Telegram), wav, webm, flac. AMR и 3GP сервисы обычно не
  принимают — такие записи проект переводит в mp3 у себя. Размер — до 25 МБ (около 25 минут разговора в mp3); длинные
  записи режутся на части у проекта.
- Кыргызскую и другие не самые распространённые речи сервисы распознают по-разному — проверьте на своих записях.
- «Кратко» видит последние 80 сообщений (не больше 24 000 знаков), оценка — последние 20: о давнем начале длинной
  переписки ИИ не знает.
- ИИ может ошибиться: краткое содержание и оценка — подсказка, а не решение; улучшенный текст менеджер проверяет перед
  отправкой.
- ИИ отвечает на языке переписки или черновика: клиент пишет по-английски — пересказ тоже будет по-английски.
