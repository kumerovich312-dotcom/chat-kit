# План работ: нейтральная основа переписки

Решение пользователя 27.09.2026 (второе, уточняющее): chat-kit — **нейтральная основа** переписки с клиентами для
любых его проектов. Каждый проект берёт её и докручивает под свою отрасль (у клиники — пациенты и запись на приём,
у агентства — кандидаты и вакансии, у магазина — заказы). Названий конкретных проектов в наборе нет.

**Подход:** одна основа + докрутка в проекте. Набор — один пакет с номером версии; проект меняет слова, цвета, что
включено, добавляет свои карточки и кнопки — не правя основу. Улучшения основы получают все проекты сменой версии.

## Выбор пользователя 27.09.2026

| Раздел | Что делаем |
|---|---|
| Докрутка | паспорт проекта (слова, цвета, что включено); свои карточки в ленте; свои кнопки в поле ввода; инструкция для ИИ проекта |
| Под ключ | пример проекта целиком (образец, с которого ИИ проекта списывает) |
| Команда | статусы и «отложить до»; метки; «коллега уже отвечает»; раздача новых по очереди (с ответственным); статистика ответов |
| Окно | ответ с цитатой; старые сообщения при прокрутке вверх; все файлы клиента; тёмная тема; запись голосового |
| ИИ | голосовое → текст (кнопка «Расшифровать»); краткое содержание; «улучшить текст»; настроение и срочность |
| Каналы | Telegram-бот; чат на сайте; WhatsApp через GREEN-API; Instagram; почта; звонки (Nextbot и студия уже есть) |
| Ещё (слова пользователя) | фильтр сообщений в переписке; кнопка транскрибации |

Не выбрано (можно добавить позже): замена любой детали окна своей, демо в трёх «одеждах», готовая база и готовые адреса
сервера как часть набора, упоминания коллег, рабочие часы и автоответ, реакции, отправка позже, уведомления на телефон,
эмодзи, черновики, перевод, официальный WhatsApp, WhatsApp по QR.

## Порядок (✓ — сделано)

1. ✓ Нейтральность: убрать названия проектов из кода, описаний и демо; подключение к шлюзу одного проекта — из основы
   убрать; общие места Nextbot (функции бота, заявка) — без привязки к отрасли.
2. ✓ Основа для новых частей: цитата, карточка проекта, расшифровка у файла, звонок как событие канала, статус, метки,
   ответственный, оценка ИИ, присутствие коллеги.
3. ✓ Каналы (каждый — своё подключение с тестами): Telegram, Instagram, GREEN-API, почта, звонки, чат на сайте.
4. ✓ «Розетка ИИ»: расшифровка, краткое содержание, улучшить текст, настроение и срочность — проект подключает Claude
   или свою студию.
5. ✓ Команда: статусы, «отложить до», метки, раздача по очереди, статистика (TypeScript + подзапрос для Postgres).
6. ✓ Паспорт проекта и окно (кроме страницы статистики — ждёт выбора вида): слова отрасли, свои карточки и кнопки, цитата, фильтр, файлы клиента, запись голосового,
   тёмная тема, кнопки ИИ. Внешний вид — сначала 2–3 варианта пользователю.
7. Пример проекта целиком (Next.js, examples/next) — в работе; ✓ инструкция для ИИ проекта — docs/FOR-AI.md.
8. Выпуск — по «да» пользователя.

## Вид окна — выбор пользователя 27.09.2026

- Фильтр сообщений — кнопка в шапке, строка кнопок открывается над лентой.
- Все файлы клиента — галерея поверх окна (кнопка в шапке).
- Статус, метки и ответственный — отдельной полосой под шапкой.
- Настроение и срочность в списке — надпись под именем, только когда есть что сказать.
- Свои кнопки проекта в поле ввода — кнопка «+» с меню.
- Краткое содержание — по кнопке «Кратко», плашка сверху ленты.
