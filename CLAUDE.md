## ЖЕЛЕЗНЫЕ ПРАВИЛА

- **Чужие проекты — только чтение.** Атлас, TishCRM и студию в этом чате не менять и не запускать (стенд Атласа 30004
  не трогать). Параллельно идут другие чаты пользователя: «Провести ревизию aibots — этап 1 плана», «Работа над Dental AI
  CRM», чаты про сайты и чат Атласа. TishCRM клонируется во временную папку только для чтения, туда ничего не отправляем.
- **GitHub.** Репозиторий `kumerovich312-dotcom/chat-kit` **открытый** (решение пользователя 27.09.2026): его видят все.
  Поэтому в нём нет секретов и нет подробностей устройства закрытых Атласа и TishCRM (серверы, выкладка, служебные
  ключи и адреса) — только то, что нужно набору. Новые выпуски (`npm run release`) — по «да» пользователя.
- **Секреты.** Не просить и не хранить: ни ключей Nextbot, ни адресов вебхуков, ни паролей. В тестах и демо —
  только обезличенные примеры: без настоящих телефонов, имён и ключей. Тестовые «ключи» — только вида
  `test-secret-not-real-…` (так требует проверка секретов студии); не писать имён вида `…sk-` + 20 знаков
  (например `task-…`, `desk-…`) — их ловит поиск секретов студии.
- **Код набора собирается во всех трёх проектах:** строгие флаги TypeScript студии (`strict`, `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`) — и у нас; без Tailwind (свои стили, классы `ck-…`); без `blob:`-адресов для картинок
  и голосовых (CSP студии) — только прямые ссылки сайта; текст бота — не как HTML.
- **Порты.** Демо-страница — 30030. Порты ниже 15000 на этом компьютере Windows резервирует блоками — не использовать.
  Заняты другими проектами: 30003, 30004, 30014, 30020, 30097, 30099, 35432.
- **Node и npm.** В bash `node` доступен (v24), npm — через `"C:\Program Files\nodejs\npm.cmd"`.
- **Запись файлов.** Код с обратной косой чертой (регулярки) — только через Edit/Write: heredoc и `node -e` теряют `\`.
- **Обходы Nextbot — только в подключении Nextbot.** Разбор «Полного диалога», угадывание времени и автора в ядро не идут.
- **Идеи для студии** (действия у сообщения, черновик ответа бота, пауза/вернуть боту/не отвечать) — спрашивать
  пользователя, когда делаем места для расширений в окне переписки.
