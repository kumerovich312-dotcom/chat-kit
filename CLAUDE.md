## Устройство (подробно — `docs/ARCHITECTURE.md`)

- `src/core` — ядро без зависимостей: модель, «ждут ответа» (`waitSince` + `waitSinceSql`), порядок, телефоны, файлы,
  разметка, время, ссылки, форма поля ввода.
- `src/server` — «розетка» `ChannelAdapter`, «переходник» `ChatStore`, приём `ingest`, скачивание, подписи ссылок,
  переходник «в памяти» для тестов.
- `src/nextbot`, `src/wa-gateway`, `src/studio` — подключения каналов.
- `src/ui` — окно (React 19), стили `src/ui/styles.css`. Серверные части (`ChatThread`, `DialogList`, `DialogHeader`,
  `ChatWindow`, `Attachment`) — без `"use client"`: функции в них передаются только как render-функции или
  действия-формы (server actions).
- `demo/` — демо-страница на Vite (выдуманные клиенты), `scripts/demo-assets.mjs` делает голосовые и документы,
  `tests/` — vitest (ядро, Nextbot, шлюз, студия, окно в jsdom, серверная отрисовка, проверка архива выпуска).

## Как запускать

- Демо: через превью `chat-kit-demo` (`.claude/launch.json`) или `npm run demo` → http://127.0.0.1:30030;
  тема (Атлас / TishCRM / Студия) и «кто смотрит» — переключатели вверху страницы; в адресе — `?dialog=…`, `show=…`
  (фильтр списка), `q=…` (поиск).
- Проверки: `npm run check` (типы + тесты + сборка). npm в bash — `"C:\Program Files\nodejs\npm.cmd"`, либо
  `node node_modules/vitest/vitest.mjs run`, `node node_modules/typescript/bin/tsc --noEmit -p tsconfig.json`.
- Сохранение работы: коммит в рабочей ветке и `git push origin HEAD:main`.
- Выпуск: поднять `version` в package.json + раздел в `CHANGELOG.md` → `npm run release -- --dry-run` → по «да»
  пользователя `npm run release` (метка vX.Y.Z и выпуск с архивом на GitHub). Ссылки в README и CONNECT.md — на новую
  версию.

## Подводные камни (уже встречались)

- Импорты в `src` — с расширением `.js` (иначе собранный код не откроет Node).
- `exactOptionalPropertyTypes`: необязательные поля пишем `?: T | null | undefined`.
- Vite не отдаёт файлы, появившиеся в `public/` после запуска: файлы демо делаются до старта сервера (в `vite.config.ts`).
- В jsdom нет `scrollTo` — вызывать `el.scrollTo?.()`.
- Картинки докачиваются после открытия ленты — прокрутку вниз держит `ResizeObserver` в `ChatScroller`.
- Проверка архива (`tests/package.test.ts`) ищет в `dist` строки, похожие на секреты, и «настоящие» телефоны — примеры
  номеров в комментариях только из нулей: `+996 555 00-00-01`.
- Лаймовый акцент студии плохо читается текстом: для ссылок, галочек и значков — свои переменные (`--ck-link`,
  `--ck-tick`, `--ck-accent-ink`), цвета значков каналов — постоянные.

- **Секреты.** Не просить и не хранить: ни ключей Nextbot, ни адресов вебхуков, ни паролей. В тестах и демо —

  `test-secret-not-real-…` (так требует проверка секретов студии); не писать имён вида `…sk-` + 20 знаков
  (например `task-…`, `desk-…`) — их ловит поиск секретов студии.
- **Код набора собирается во всех трёх проектах:** строгие флаги TypeScript студии (`strict`, `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`) — и у нас; без Tailwind (свои стили, классы `ck-…`); без `blob:`-адресов для картинок
  и голосовых (CSP студии) — только прямые ссылки сайта; текст бота — не как HTML.
- **Порты.** Демо-страница — 30030. Порты ниже 15000 на этом компьютере Windows резервирует блоками — не использовать.
  Заняты другими проектами: 30003, 30004, 30014, 30020, 30097, 30099, 35432.
- **Node и npm.** В bash `node` доступен (v24), npm — через `"C:\Program Files\nodejs\npm.cmd"`.
- **Запись файлов.** Код с обратной косой чертой (регулярки) — только через Edit/Write: heredoc и `node -e` теряют `\`.
- **Обходы Nextbot — только в подключении Nextbot.** Разбор «Полного диалога», угадывание времени и автора в ядро не идут.
- **Идеи для студии** (действия у сообщения, черновик ответа бота, пауза/вернуть боту/не отвечать) — спрашивать
  пользователя, когда делаем места для расширений в окне переписки.
